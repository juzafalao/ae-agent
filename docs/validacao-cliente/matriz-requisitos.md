## Observações críticas adicionais (fora da matriz)
- **O prompt induz invenção.** `src/prompt.js:60-62` manda "criar histórias verossímeis de franqueados" com valores de faturamento. `src/prompt.js:235` cita estatística sem fonte. `src/prompt.js:82` sugere dizer "vi que você abriu o material", mas não há rastreamento de abertura no código. Tudo isso contradiz `src/prompt.js:290` ("Não invente números").
- **O prompt promete coisas que o código não faz.** O follow-up "após algumas horas" (`src/prompt.js:76`) e o "vou confirmar com a equipe e já te respondo" (`src/prompt.js:293`) dependem de agendador ou retorno, e não existe nenhum.
- **Concorrência.** Não há fila ou lock por telefone (`src/server.js:78`). Duas mensagens seguidas geram duas chamadas paralelas sobre o mesmo array de histórico (`src/memory.js:16-23`).
- **Histórico pode começar com `assistant`** após o corte em 20 itens (`src/memory.js:21-23`). Se a API rejeitar isso, o lead recebe a mensagem de erro em loop. **Não verificável** sem chamar a API.
- **Modelo fixo `claude-sonnet-4-20250514` com SDK 0.24.3** (`src/agent.js:96`, `node_modules/@anthropic-ai/sdk/package.json:3`). Se o modelo estiver indisponível, toda mensagem cai no erro genérico. **Não verificável** offline; confirmar antes da demo.
